# 《浅滩鱼悔》规则文档（RULES.md）

> 规则优先级：https://www.thefamilygamers.com/shallow-regrets/ 为最高优先级权威来源；
> 本文件及任何其它资料（含 GitHub 参考实现）与它冲突时，一律以该网址规则为准。

## 一、目标

在灰雾笼罩的海面下钓起恐怖之物。对局结束时，钓获分值最高者获胜。

## 二、组件

18 张鱼卡，字段：`id` / `name` / `points`（分值）/ `strength`（所需钩数 0-5，即难度）/
`hooks`（钓获后提供的钩数）/ `type`（`fair` 正品 | `foul` 污秽）/ `ability`（一次性能力）/ `art`（卡图）。

- 小鱼（strength 0，开局易钓）：沙丁鱼、小丑鱼、河豚、灯笼鱼、水母（污秽）、怪脚（污秽，-1 分）。
- 中型鱼（strength 1-2）：昼章鱼、魟鱼、七鳃鳗、梭鱼、海鳗、眼球怪（污秽）、美人鱼（污秽）、巨型章鱼。
- 大鱼（strength 3-5）：皇带鱼、永恒乌贼（污秽）、凯尔派（污秽）、克拉肯。

## 三、开局

1. 18 张鱼卡洗乱后分成 6 个浅滩，每堆 3 张，牌面朝下。
2. 保证至少 3 个浅滩的顶牌是"小阴影"（strength ≤ 0 的小鱼），确保开局可钓。
3. 玩家初始钩数 = 0。

## 四、回合流程

每回合按顺序执行：

1. **能力阶段**：可发动任意数量已钓能力鱼的能力（每种能力整局仅一次，发动后该鱼横置）。
2. **抽牌**：从任意浅滩取 2 张牌（可在同一或不同浅滩；同一浅滩最多抽其现有张数）。
3. **钓走/放回**：
   - 若钩数足够，可钓走 1 张（每回合最多钓 1 条）；
   - 其余牌放回浅滩；
   - 若两张都无法满足强度，则全部放回，回合结束。

## 五、钩数机制

- 初始钩数 0。
- 钓到的鱼提供钩数（`hooks` 字段）：**仅分值 ≤ 3 的鱼提供钩数（各 1 钩）**；
  分值 > 3 的鱼（梭鱼及以上）**不提供钩数**——大鱼是"终局渔获"，钩数只能靠小鱼逐步积累（平衡性调整）。
- 当前钩数 = 已钓获鱼提供的钩数之和，用于满足更强鱼的要求（`strength`）。
- 注意：`strength`（所需钩数）与 `hooks`（提供钩数）是分离字段。小鱼 strength=0 但 hooks=1。

## 六、放回浅滩规则

1. 有可钓走的鱼时，必须先钓走一条，之后才能放回。
2. **浅滩上限 3 张**：已有 3 张牌的浅滩不可作为放回目标（与开局 6×3 布置一致）。
3. 放回目标按优先级：
   - 若有空浅滩，必须放回空浅滩；
   - 否则盖在"大阴影"（顶牌 strength ≥ 1）之上；
   - 除非所有浅滩顶牌都是小阴影（strength ≤ 0），否则不能盖小阴影。

## 七、能力明细

| 能力 | 说明 | 目标 |
|------|------|------|
| draw_extra | 本回合多抽 1 张牌 | 无 |
| peek_shoal | 偷看一个浅滩的顶牌 | 浅滩 |
| force_exhaust | 强制对方横置其一条鱼（对方免疫时不可用） | 对方已钓的鱼 |
| swap_fish | 与对方交换一条鱼（对方免疫时不可用） | 自己与对方各一条 |
| shuffle_shoals | 洗乱所有浅滩并重新布置（保证至少 3 个顶牌是小阴影） | 无 |
| immunity | 本回合免疫对方的横置/交换效果 | 无 |

每种能力整局仅一次；发动后该鱼横置（旋转 90° 灰化）。

## 八、终局与计分

1. **终局条件**：全部鱼被钓光，或没有任何玩家能钓起"可接触"的鱼（每个浅滩顶牌与次顶牌均无人可钓）。
2. **计分**：各玩家钓获分值之和。
3. **污秽惩罚**：钓到最多"污秽鱼"的玩家额外 -2 分（并列都扣）。
4. **胜负**：总分最高者胜。

## 九、平局

总分并列最高者共享胜局（平局）。结算页显示"平局！"。

## 十、M2 单人 AI 对战

- 玩家 vs 启发式 AI 电脑。
- AI 决策优先级：能否满足钩数 → 优先高分且非污秽 → 评估污秽风险 → 抢关键能力鱼。
- AI 必须走与玩家完全相同的动作接口与规则校验，禁止作弊。

## 十一、M5 Solo 玩法《渔夫与青蛙》

### 11.1 模式定位

玩家 vs 预设脚本对手"渔夫与青蛙"。脚本对手**不是**启发式评估 AI（区别于 M2），
而是严格按固定剧本执行：固定取牌/钓走/放生优先级、固定能力发动时机、固定行动节奏，无随机与评估分支。

### 11.2 脚本对手构成（6 张固定卡牌）

脚本对手由 6 张固定卡牌定义其"目标清单"（即其偏好的渔获），配置在 `js/solo/soloScript.js`：

| 优先级 | 卡牌 | 分值 | 所需钩数 | 能力 |
|--------|------|------|----------|------|
| 1 | 克拉肯 kraken | 8 | 5 | shuffle_shoals |
| 2 | 凯尔派 kelpie | 7 | 4 | shuffle_shoals |
| 3 | 皇带鱼 oarfish | 6 | 3 | draw_extra |
| 4 | 永恒乌贼 eversquid | 6 | 3 | draw_extra |
| 5 | 梭鱼 barracuda | 4 | 2 | 无 |
| 6 | 海鳗 morayEel | 4 | 2 | immunity |

### 11.3 先后手

玩家可在设置中选择"玩家先手"或"脚本先手"（默认玩家先手）。先手方为对局中第一个行动者。

### 11.4 脚本行动规则（确定性剧本）

脚本对手与玩家使用同一套核心规则（取牌、强度、放生、能力、计分、污秽惩罚，复用 `js/core/`）。
其每一步决策均为纯函数（输入状态快照 → 输出动作）：

1. **能力阶段**：按固定顺序（克拉肯 → 凯尔派 → 皇带鱼 → 永恒乌贼 → 海鳗）依次尝试发动
   已钓且未横置的能力鱼（全部为无目标能力，直接发动）。
2. **取牌**：优先从"顶牌或次顶牌为目标清单内卡牌"的浅滩取牌（按目标清单优先级）；
   否则取最左非空浅滩。
3. **钓走/放回**：
   - 若抽到目标清单内的牌且钩数足够 → 按目标清单优先级钓走 1 张；
   - 否则钓走抽到牌中分值最高且非污秽、且钩数足够的牌；
   - 否则全部放回：先放污秽牌，固定放回最左合法浅滩。

### 11.5 特色机制：压迫节奏

脚本对手每回合固定行动（无随机），且一旦抽到目标清单内的可钓牌**必定钓走**。
这形成"抢大鱼"的压迫节奏——目标清单内的 6 张大鱼会被脚本对手逐步抢走，玩家需尽快钓起它们。

### 11.6 结算与评价

对局结束（复用第八节终局与计分）后，除比分外，按以下特色目标评估玩家表现（每项 1 星）：

1. ⭐ 总分高于脚本对手；
2. ⭐ 钓到克拉肯（kraken）；
3. ⭐ 全程未钓到任何污秽鱼；
4. ⭐ 在脚本对手之前钓到至少 3 张目标清单内的卡牌（抢鱼成功）。

星级评价等级：

| 星级 | 评价 |
|------|------|
| 0-1 | 浅滩之耻 |
| 2 | 勉强及格 |
| 3 | 合格渔夫 |
| 4 | 深海传奇 |

结算页展示双方钓获明细、污秽惩罚、特色目标达成情况与评价；提供"再来一局"与"返回首页"。
